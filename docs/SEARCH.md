# ค้นหาคำบรรยายในแกลเลอรี

ค้นจากคำบรรยายที่โหลดในโฟลเดอร์ปลายทางปัจจุบัน ทำใน frontend ทั้งหมด ไม่เรียก Python, Florence หรือ Gemini และไม่แก้คำบรรยายใน DB

ลำดับผลคือคำตรง คำพ้อง/ชื่อเรียกอื่น แล้วคำพิมพ์ผิดเล็กน้อย หากคะแนนเท่ากันคงลำดับเดิมของรูป ค้นหลายคำต้องพบทุกคำในคำบรรยายรูปเดียวกัน เช่น `หมา โซฟา` หรือ `หมาบนโซฟา` ค้นรูปที่มีทั้งสองอย่างได้ ตัวเชื่อมทั่วไป เช่น บน ใน และ พร้อม ไม่จำเป็นต้องตรงกัน

ใช้ `Intl.Segmenter('th')` ตัดคำโดยเก็บสระ/วรรณยุกต์ไว้ ตรวจขอบเขตคำเพื่อไม่ให้ `หมา` ไปตรง `หมากรุก` ใช้ Fuse.js คัดคำใกล้เคียงจากคำบรรยายและคลังชื่อเรียก จากนั้นตรวจระยะห่างของทั้งคำอีกครั้ง เพื่อไม่ให้ `จักยาน` ถูกแก้เป็น `จักรยานยนต์` เพียงเพราะคำขึ้นต้นคล้ายกัน

เมื่อค้นหลายคำ จะจับชื่อเรียกในคลังที่ยาวที่สุดก่อน เช่น `น้องหมา คาเฟ่` เป็นสองคำค้น ไม่แยก `น้อง` ออกจาก `หมา` และไม่จำเป็นต้องมีคำว่า “น้อง” อยู่ในคำบรรยาย ใช้ได้กับคำติดกัน เช่น `น้อนหมาบนโซฟา` ด้วย

คำยาว 4–7 ตัวอักษรยอมผิดได้ 1 ตำแหน่ง คำตั้งแต่ 8 ตัวอักษรยอมได้ 2 ตำแหน่ง และรองรับการสลับอักษรติดกันหนึ่งคู่ เช่น `ทะลเ` → `ทะเล` ไม่ใช้ fuzzy กับคำสั้นกว่า 4 ตัวอักษรเพื่อลดผลที่ไม่เกี่ยวข้อง เช่น หมา/หมอ ภาษาไทยนับตัวอักษรรวมสระและวรรณยุกต์ในขั้นนี้ การจับคู่คล้ายกันจำกัดคำไม่เกิน 32 ตัวอักษร ส่วนคำตรงและการค้นหลายคำยังใช้ได้กับข้อความยาว

ไฟล์หาย/ลบแล้วและรูปที่ไม่มีคำบรรยายไม่อยู่ในผลเมื่อมีคำค้น เมื่อล้างคำค้นจะแสดงรายการเดิมทั้งหมด ดัชนีอัปเดตตามคำบรรยายและสถานะไฟล์ มีแคชการตัดคำต่อรูปเพื่อไม่ตัดข้อความเดิมซ้ำระหว่างรับผล AI

## คลังคำ

แก้คำทั้งหมดได้ใน `frontend/app/data/searchSynonyms.json` ไฟล์เดียว แต่ละอาร์เรย์คือกลุ่มคำที่ค้นแทนกันได้ มี **476 กลุ่ม และ 1,357 คำ/รูปสะกดที่ไม่ซ้ำ** รวมคำพ้อง ภาษาพูด คำวัยรุ่น และรูปสะกดของคำทับศัพท์แล้ว เพิ่มคำใหม่ในกลุ่มเดิม หรือเพิ่มอาร์เรย์ใหม่สำหรับความหมายใหม่

ชื่อเรียก เช่น `น้อนหมา` → `สุนัข`, `มอไซค์` → `จักรยานยนต์`, `ไอติม` → `ไอศกรีม`, `ชิล` → `พักผ่อน` ค้นจากคำในคำบรรยายเท่านั้น ไม่อนุมานว่ารูปทะเลทุกใบเป็นการพักผ่อน คำกำกวม เช่น `จึ้ง` หรือ `น้อน` เดี่ยว ๆ ไม่ผูกกับวัตถุใด

เพิ่มคำที่ใช้กับสถานที่ ยานพาหนะ สัตว์ อาหาร เครื่องใช้ เครื่องแต่งกาย กิจกรรม และงานพิธี เช่น โกดัง/คลังสินค้า รถสิบล้อ/รถบรรทุกสิบล้อ แซนวิช/แซนด์วิช และตากล้อง/ช่างภาพ

การจับคู่เป็นชื่อเรียกสำหรับค้นรูป คำบางคำแทนกันไม่ได้ทุกบริบท จึงควรตรวจผลค้นจริงก่อนเพิ่มคำลงกลุ่ม ระบบค้นตามข้อความ ไม่ได้แยกความหมายตามบริบท เช่น คำว่าแพะในแพะรับบาป หรือมะม่วงที่อยู่ในชื่อต้นไม้ อาจยังตรงกับคำค้นได้ ไม่ใส่กลุ่มที่ชัดเจนว่าเป็นคนละชนิด เช่น กบ/คางคก หรือเรือใบ/เรือคายัค

ใช้ Fuse.js ที่ติดตั้งกับ frontend อยู่แล้ว ไม่ต้องดาวน์โหลดโมเดลค้นหาเพิ่ม

## ตรวจสอบ

```bash
cd frontend
npm run test:search
npm run build
```

เทสต์ครอบคลุมการจัดอันดับ คำพ้องสองทิศ คำผิด/สลับอักษร การค้นหลายคำ การกันคำที่คล้ายแต่คนละวัตถุ ไฟล์หาย คำบรรยายที่เพิ่งบันทึก และการไม่แก้ข้อมูลต้นฉบับ ยังต้องทดลองคำค้นจริงใน Wails บน Windows/Mac เพื่อประเมินความตรงใจ ไม่ได้วัดความแม่นยำของทั้งคลังภาพ
