# ย้ายหรือสำรองรูป

1. เปิดหน้า **ย้าย / สำรองรูป** แล้วเลือกโฟลเดอร์ต้นทางและปลายทาง
2. เลือก **ย้ายรูป** เพื่อนำไฟล์ออกจากต้นทางเมื่อสำเร็จ หรือ **สำรองแบบคัดลอก** เพื่อเก็บต้นฉบับไว้
3. สแกนและเลือกรูปที่ต้องการ
4. กดปุ่มย้ายหรือสำรอง แล้วตรวจโฟลเดอร์และข้อความในหน้าต่างยืนยัน
5. ดูความคืบหน้าและผลสำเร็จ ข้าม หรือผิดพลาด

ทั้งสองโหมดข้ามไฟล์ชื่อซ้ำโดยไม่เขียนทับ การสำรองทำได้ระหว่างวิเคราะห์ภาพ ส่วนการย้ายและลบรูปที่กำลังวิเคราะห์จะรอจนบันทึกผลเสร็จ

ผลการสำรองยังแสดงเป็นผลการสำรอง แม้เปลี่ยนตัวเลือกของงานถัดไปเป็นย้ายแล้ว ประวัติของทั้งสองโหมดอยู่ในหน้าประวัติและตรวจสอบ

คำบรรยายของต้นทางยังอยู่กับต้นทาง ไฟล์สำเนาที่ปลายทางมีรายการของตัวเองและยังไม่ได้วิเคราะห์ ตามพฤติกรรมของฟังก์ชันคัดลอกเดิม
