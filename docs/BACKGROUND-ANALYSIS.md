# วิเคราะห์ภาพเบื้องหลัง

เมื่อกดวิเคราะห์ แถบสถานะ AI จะแสดงทุกหน้า แอปต้องเปิดอยู่จนงานจบ

- ไปแกลเลอรี ค้นหา และเปิดดูคำบรรยายที่แปลเสร็จแล้วได้ทันที
- เปลี่ยนโฟลเดอร์ต้นทางหรือปลายทาง และย้ายรูปอื่นได้ระหว่างรอ AI
- รูปที่กำลังวิเคราะห์ยังเลือกย้ายหรือลบไม่ได้ เมื่อบันทึกคำบรรยายเสร็จจึงทำได้
- วิเคราะห์ได้ทีละงาน ปุ่มเริ่มวิเคราะห์จะเปิดอีกครั้งเมื่องานปัจจุบันสิ้นสุด
- ผลและข้อผิดพลาด AI แสดงแยกจากผลการย้ายไฟล์
- หน้าจัดเก็บมีตัวเลือกย้ายและสำรองแบบคัดลอก การสำรองเก็บต้นฉบับไว้และทำได้แม้รูปนั้นยังวิเคราะห์อยู่

ตรวจสอบโดยใช้ไฟล์และ SQLite ชั่วคราว ไม่เรียก Gemini:

```powershell
go test -overlay tests/go-overlay.json ./... -count=1 -timeout 90s
node tests/frontend/test_background_analysis.cjs
node tests/frontend/test_backup_modes.cjs
cd frontend
npm test
```

การทดสอบครอบคลุมการย้ายรูปที่เสร็จแล้วระหว่างอ่านรูปอื่น การป้องกันย้าย/ลบรูปที่ยังไม่เสร็จ การสแกนระหว่างวิเคราะห์ การเปลี่ยนโฟลเดอร์ และคำตอบ metadata ที่มาช้า
