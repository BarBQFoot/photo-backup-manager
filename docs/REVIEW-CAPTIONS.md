# ตรวจคำบรรยายหลังแปลครบ

สร้างหน้าตรวจแบบออฟไลน์ โดยตรวจ IDs, ข้อความต้นทาง, คำแปลที่ผ่าน validation และการมีอยู่ของไฟล์รูปก่อน:

```powershell
.\.venv\Scripts\python.exe tools/prepare_caption_review.py --run results/florence_20261022_222031_582707
Invoke-Item results/florence_20261022_222031_582707/caption_review.html
```

สคริปต์ไม่เรียก API และไม่แก้ฐานข้อมูล สร้าง `caption_review.html` กับ `caption_review_verification.json` ใน run เดิม ต้องเก็บรูปไว้ที่พาธเดิม หรือสร้างหน้าใหม่หลังย้ายรูปและปรับพาธรายงานให้ถูกต้อง

หน้า HTML มีภาพ คำบรรยายอังกฤษ และคำแปลไทย เลือกตรวจชุดสุ่ม 50 รูป (seed 20261022) หรือทุกรูปได้ แยกประเมินสองอย่าง:

- ภาพ: ตรงภาพ / ถูกบางส่วน / ผิดใจความหลัก
- การแปล: ไทยตรงต้นฉบับอังกฤษหรือไม่

บันทึกคำแก้และหมายเหตุได้ ผลตรวจเก็บใน localStorage ของเบราว์เซอร์ ถ้าเบราว์เซอร์ไม่รองรับจะแจ้งเตือน ต้องกดดาวน์โหลดผลตรวจ JSON ก่อนปิดหน้าเพื่อเก็บผลอย่างแน่นอน การแก้ยังไม่เขียนกลับคำบรรยายหรือฐานข้อมูล คะแนนในหน้าเป็นสัดส่วนของรูปที่ตรวจในมุมมองปัจจุบันเท่านั้น ไม่ใช่ความแม่นยำของทั้ง 1000 รูป

ผลตรวจโครงสร้างรอบปัจจุบัน: 1000 IDs ไม่ซ้ำ ตรงกับต้นทางและคำตอบรายชุด คำแปลไม่ว่าง สถานะ translated ทุกภาพ และพบไฟล์รูปครบ 1000 ไฟล์ ยังรอคนตรวจเนื้อหาภาพจริง

macOS/Linux ใช้ Python ของ environment นั้น และเปิด HTML ในเบราว์เซอร์ ต้องมีรูปกับรายงานพาธที่ถูกต้องบนเครื่องนั้นด้วย ยังไม่ได้ทดสอบ UI บนทุกระบบ
